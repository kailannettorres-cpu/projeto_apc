Algoritmos

Um algoritmo é uma sequência de passos, em ordem, para resolver um problema ou realizar uma tarefa.

Exemplo do dia a dia: calcular a média de um aluno.

1. Ler as notas. 2. Somar as notas. 3. Dividir a soma pela quantidade de notas. 4. Mostrar o resultado.

Em Python, esse algoritmo fica assim: media = (nota1 + nota2) / 2 e depois print(media).

Um bom algoritmo é claro, tem começo e fim, e cada passo pode ser executado sem ambiguidade.

Antes de programar, escreva os passos em português. Depois, é só traduzir cada passo para código.
